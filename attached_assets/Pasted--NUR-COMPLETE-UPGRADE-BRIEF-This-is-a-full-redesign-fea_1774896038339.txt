## PART 1 — VISUAL REDESIGN

### The Problem With The Current Design
The current UI looks like a clean dark app but lacks visual hierarchy, depth, and identity. It needs to feel like a £4/month premium product, not a free utility. Compare to apps like Nusuk, Gentler Streak, Headspace — premium apps that use space, typography, and light intentionally.

### New Design Direction: "Sacred Light"
The concept is that Nur (light) emanates from within the dark. Every screen should feel like you're looking at something glowing softly in darkness — not just dark backgrounds with text.

## PART 8 — QIBLA COMPASS SCREEN

**Implementation using device compass + location:**
```typescript
import { Magnetometer } from 'expo-sensors';
import * as Location from 'expo-location';

// Calculate Qibla direction from current coords to Mecca (21.4225° N, 39.8262° E)
function calculateQiblaDirection(lat: number, lng: number): number {
  const meccaLat = 21.4225 * (Math.PI / 180);
  const meccaLng = 39.8262 * (Math.PI / 180);
  const userLat = lat * (Math.PI / 180);
  const userLng = lng * (Math.PI / 180);
  
  const dLng = meccaLng - userLng;
  const x = Math.cos(meccaLat) * Math.sin(dLng);
  const y = Math.cos(userLat) * Math.sin(meccaLat) - Math.sin(userLat) * Math.cos(meccaLat) * Math.cos(dLng);
  
  return ((Math.atan2(x, y) * (180 / Math.PI)) + 360) % 360;
}

// Subscribe to magnetometer for live compass heading
Magnetometer.addListener(({ x, y }) => {
  const heading = Math.atan2(y, x) * (180 / Math.PI);
  // Rotate compass needle: qiblaDirection - heading
});
```

```typescript
      const target = new Date();
      target.setHours(h, m, 0, 0);
      
      if (target < now) target.setDate(target.getDate() + 1);
      
      const diff = Math.floor((target.getTime() - now.getTime()) / 1000);
      const hours = Math.floor(diff / 3600);
      const mins = Math.floor((diff % 3600) / 60);
      const secs = diff % 60;
      
      if (hours > 0) setCountdown(`${hours}h ${mins}m ${secs}s`);
      else if (mins > 0) setCountdown(`${mins}m ${secs}s`);
      else setCountdown(`${secs}s`);
    }, 1000);
    
    return () => clearInterval(interval);
  }, [targetTime]);
  
  return countdown;
}
```

## PART 18 — FUTURISTIC DESIGN PRINCIPLES

Every design decision should ask: "Does this feel like a £4/month premium Islamic app or a free utility?"

**Premium signals to include:**
- Smooth spring animations on every state change (react-native-reanimated)
- Haptic feedback on all interactive elements
- Gold glows on active/hero elements
- Geometric Islamic pattern everywhere at low opacity
- Arabic calligraphy-style text for key religious content
- Micro-animations: prayer marked done → teal sweep animation
- Counter increment → brief scale pulse
- Screen transitions → fade, not slide
- Loading states → gold shimmer skeleton, not spinner

**Things that make apps feel cheap — avoid all of these:**
- Static/flat prayer rows with no visual feedback
- Generic white loading spinners
- Harsh red error states
- System default fonts anywhere
- Solid flat backgrounds (use subtle gradients)
- Missing haptics on interactive elements
- Inconsistent border radius
- Full-width flat buttons (use rounded, gold, with slight glow)
