## WHAT NUR IS

**Nur** (Arabic: نور, meaning "light") is a premium Islamic lifestyle app for iOS and Android. It is a Muslim routine operating system — helping Muslims stay consistent with daily worship, Quran goals, and zakat planning.

**Core positioning:** The privacy-first, trust-centered alternative to Muslim Pro and similar apps. No ads. No data selling. No tracking. Ever. This is not just an ethical stance — it is the entire competitive advantage. Muslim Pro was caught selling user location data to the US military. Tens of thousands of users deleted it. The Muslim community is actively looking for a trustworthy alternative. Nur is that alternative.

**Target users:**
- Young Muslim professionals in the UK (primary)
- Muslim families who want shared household goals
- Practicing Muslims who want structure and consistency
- UK Muslims aged 18–40 who use smartphones daily

**Tone and feel:** Premium, spiritual, honest. Like Nusuk (the Saudi Ministry of Hajj app) — dark near-black backgrounds, warm gold (#c9a84c) as the primary accent, subtle geometric Islamic lattice patterns as texture, DM Serif Display for headings. Never cheesy. Never cliché. Never gamified in a way that feels disrespectful to worship.

**Business model:** Direct-to-consumer subscription only. No mosque B2B (ruled out). No ads. No data selling.
- Free tier: prayer tracker, basic Quran log, zakat calculator
- Premium: £3.99/month — push notifications, streak tracking, Ramadan mode, widgets, full Quran goals
- Family: £6.99/month — up to 6 profiles, shared goals, parent dashboard
- Payments via RevenueCat (handles iOS + Android in-app purchases)

### PRIORITY 4 — Supabase database schema

Run these SQL statements in your Supabase SQL editor to create the schema:

```sql
-- Users profile (extends Supabase auth.users)
create table public.profiles (
  id uuid references auth.users(id) primary key,
  display_name text,
  arabic_name text,
  location_city text,
  location_lat float,
  location_lng float,
  prayer_method integer default 2,
  created_at timestamptz default now(),
  updated_at timestamptz default now()
);

-- Prayer logs
create table public.prayer_logs (
  id uuid default gen_random_uuid() primary key,
  user_id uuid references auth.users(id) not null,
  prayer_name text not null,           -- 'Fajr', 'Dhuhr', 'Asr', 'Maghrib', 'Isha'
  prayer_date date not null,
  completed boolean default false,
  completed_at timestamptz,
  created_at timestamptz default now(),
  unique(user_id, prayer_name, prayer_date)
);

-- Quran sessions
create table public.quran_sessions (
  id uuid default gen_random_uuid() primary key,
  user_id uuid references auth.users(id) not null,
  week_start date not null,            -- Monday of the week
  pages_read integer default 0,
  weekly_goal integer default 35,
  created_at timestamptz default now(),
  updated_at timestamptz default now(),
  unique(user_id, week_start)
);

-- Zakat calculations (save history)
create table public.zakat_calculations (
  id uuid default gen_random_uuid() primary key,
  user_id uuid references auth.users(id) not null,
  cash numeric default 0,
  gold numeric default 0,
  investments numeric default 0,
  stock numeric default 0,
  liabilities numeric default 0,
  nisab numeric default 430,
  net_wealth numeric generated always as (cash + gold + investments + stock - liabilities) stored,
  zakat_due numeric generated always as (
    case when (cash + gold + investments + stock - liabilities) >= nisab
    then (cash + gold + investments + stock - liabilities) * 0.025
    else 0 end
  ) stored,
  created_at timestamptz default now()
);

-- Row level security
alter table public.profiles enable row level security;
alter table public.prayer_logs enable row level security;
alter table public.quran_sessions enable row level security;
alter table public.zakat_calculations enable row level security;

create policy "Users can manage their own profile"
  on public.profiles for all using (auth.uid() = id);

create policy "Users can manage their own prayer logs"
  on public.prayer_logs for all using (auth.uid() = user_id);

create policy "Users can manage their own quran sessions"
  on public.quran_sessions for all using (auth.uid() = user_id);

create policy "Users can manage their own zakat calculations"
  on public.zakat_calculations for all using (auth.uid() = user_id);
```
